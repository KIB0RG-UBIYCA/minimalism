--- INSTALLATION ---
1. Download the resource pack: https://modrinth.com/resourcepack/minimalism_k/gallery
2. Open Minecraft and go to "Options" -> "Resource Packs".
3. Click "Open Pack Folder".
4. Drag and drop the downloaded ZIP file into the folder.
5. In the game, select the pack from the list and click "Done".
